# queue_q – 使用指南

[English version](USER_GUIDE.md)

> 系统界面是英文的。本指南中的按钮名称保留英文原文，并在括号中附上中文说明，方便您在屏幕上找到对应的按钮。

## 关于 queue_q

queue_q 让病人用自己的手机加入诊所房间的排队，然后可以在任何地方等候，轮到时再过来。不需要下载 App，也不需要登录。

系统有两种用户：

- **病人：** 扫描房间的 QR 码取得号码，轮到时手机会响铃提醒。
- **房间职员：** 在电脑或平板上打开房间的管理页面（host page），叫号给病人。

## 病人使用说明

### 加入排队

1. 用手机相机扫描房间的 QR 码，然后点击出现的链接。如果用电脑，请把房间的加入链接贴到浏览器里。
2. 页面会显示房间名称、正在等候的人数，以及预计等候时间。
3. 第一次使用时，请输入您的名字。电话号码可以不填。
4. 点击 **Join the queue**（加入排队）。您会得到一个号码，例如 **A001**。
5. 点击 **Turn on sound alerts**（开启声音提醒），轮到您时手机会响铃。

### 看懂您的号码卡

| 号码卡显示 | 意思 |
| --- | --- |
| Wait about 15 min | 预计还要等大约 15 分钟，并显示前面还有几个人 |
| You're next | 下一个就是您，请留在附近 |
| Please go to [房间] now | 轮到您了。手机会响铃，并显示全屏绿色画面 |
| Your place is kept while you're in [其他房间] | 您正在另一个房间看诊，这里的位置会为您保留 |
| Earlier today | 今天已完成、错过或已离开的排队 |

### 同时排多个房间

扫描另一个房间的 QR 码，然后点击 **Join the queue**（加入排队）。系统不会再问您的名字。您所有的号码都会显示在同一个页面上。

当您在一个房间看诊时，其他房间的排队会暂停保留。看完后，您会在那些房间排到下一个，也就是在当时正在看诊的人之后。

### 其他操作

- **Let the next person go first**（让下一位先）：和排在您后面的人交换位置。需要多几分钟时可以使用。
- **Leave this queue**（离开这个排队）：退出该房间的排队，您会失去原本的位置。
- **Use this phone for another patient**（这部手机给另一位病人用）：清除这部手机上的号码，让别人可以使用。

等候时请保持排队页面打开，屏幕不要关闭。锁屏的手机可能不会响铃，iPhone 尤其如此。

## 房间职员使用说明

### 打开管理页面

1. 在房间的电脑或平板上打开该房间的管理页面链接（host link）。
2. 输入房间的 PIN 码（只能是数字），然后点击 **Open host page**（打开管理页面）。设备会记住 PIN 码，所以只需要输入一次。
3. 如果不想让设备记住 PIN 码，点击 Room settings（房间设置）底部的 **Lock this device (forget PIN)**（锁定此设备，忘记 PIN 码）。

连续输错 10 次 PIN 码后，管理页面会锁定 5 分钟。

### 按钮说明

| 按钮 | 作用 |
| --- | --- |
| Call next | 叫排在第一位的病人，对方手机会响铃 |
| Finish and call next | 结束当前病人，并叫下一位 |
| Finish | 结束当前病人，但不叫下一位 |
| Ring again | 再次让当前病人的手机响铃 |
| No-show | 把没有出现的病人移到 No-shows（缺席）名单 |
| Put back in line | 把缺席的病人放回原来的位置 |
| Call now | 不按顺序，直接叫某一位病人，例如年长的病人 |
| Minutes（例如 10 min） | 修改该病人的预计看诊时间。留空则使用房间的默认时间 |

标示 **In [其他房间]** 的病人正在别的房间看诊。他们看完之前不能被叫号，所以 Call next 会跳过他们，但保留他们的位置。

### 房间设置（Room settings）

- **Open**（开放）：正常运作。
- **On break**（休息中）：病人仍可加入排队，并会看到您留下的信息，例如 "Back at 2:00 PM"（下午 2 点回来）。
- **Closed**（关闭）：不接受新病人加入。
- **Default minutes per patient**（每位病人默认分钟数）：用来计算每位病人的预计时间，除非您单独修改。

修改后请点击 **Save settings**（保存设置）。当前病人下方的统计框会显示今天已看诊的人数，以及每位病人的平均分钟数。

## 常见问题

| 问题 | 解决方法 |
| --- | --- |
| 我的手机没有响 | 点击 **Turn on sound alerts**（开启声音提醒），保持排队页面打开，屏幕不要关闭。锁屏的手机可能不会响，iPhone 尤其如此 |
| 我关掉了页面 | 再扫描任何一个房间的 QR 码，或用同一部手机和同一个浏览器打开 queueq.netlify.app，您的号码还在 |
| 系统又问我的名字 | 您用的是另一部手机或另一个浏览器，请用当初加入排队的那一个 |
| 我错过了叫号 | 请告诉房间职员，他们可以把您放回队伍中 |
| 管理页面要求输入 PIN 码 | 输入该房间的 PIN 码。如果没有，请向诊所管理员询问 |
| 显示 "Too many wrong PINs"（PIN 码错误次数太多） | 等 5 分钟后再试 |
| 画面没有更新 | 在手机上往下拉刷新，或在电脑上按 F5 |

其他问题，请询问诊所柜台。
